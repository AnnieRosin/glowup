# ✨ GlowUp · 星光工作台

> 像明星管理行程一样，精致地管理每一天 —— 一个有颜值、有温度、会上瘾的个人成长工作台。

**GlowUp** 取自英文俚语 "glow up"（闪闪发光地蜕变），献给每一个想成为更优秀女孩子的你。🌸

## 🌟 它能做什么

### 🏠 今日
- **今日三件事** —— 只聚焦最重要的 3 件，拒绝被待办清单淹没
- **八大成长板块**（内置精心设计的推荐清单，支持自定义）：
  - 🏋️ 健身运动 · 💄 变美护肤 · 📚 学习提升 · 😴 睡眠管理
  - 🥗 饮食管理 · 🌸 情绪心态 · 💰 理财成长 · ✨ 气质修养
- **24 小时时间轴** —— 日程变成时间块，一天的安排一目了然
- **周目标制** —— "每周 4 天"代替"每天必须"，坚持不再靠硬扛

### 🎮 奖励
- **星光商店** —— 打卡攒积分，兑换自己定的小奖励（奶茶、追剧、睡到自然醒）
- **经验值 & 等级** —— 从「新手星」一路升级到「闪耀女王」
- **成就徽章** —— 连续打卡、板块大满贯、单日 20 项……越努力徽章越多
- **补签卡** —— 每月 2 张，生病旅行断签也能温柔救回

### 📔 手帐
- **成就卡片墙** —— 每天全清解锁一张治愈卡片，写下一句话，攒成纪念册
- **月度主题** —— 给这个月定一个关键词（睡眠月 / 体态月）

### 📊 数据
- **自动周报** —— 完成总量、最强/最弱板块、心情关联分析、下周建议，全自动生成
- **可视化全家桶** —— 雷达图、7 天热力图、周趋势、心情 vs 完成度双轴曲线
- **节奏预测** —— 按当前进度预估本月完成率，提前踩油门

## 🚀 快速开始

无需安装任何依赖，打开即用：

```bash
git clone https://github.com/AnnieRosin/glowup.git
# 直接用浏览器打开 starlight-workbench.html 即可 ✨
```

或者部署到 GitHub Pages，手机电脑随时访问。

## 🔒 数据隐私

所有数据保存在浏览器 localStorage 中，**不上传任何服务器**，只有你自己能看见。

## 💡 设计理念

- **温柔 > 严苛**：断签不清零，失败文案是"回来就好，你的底子还在"
- **奖励真实**：积分兑换的是你自己真正想做的事，自律与快乐可以兼得
- **看见成长**：每一个勾都会变成圆环、雷达和热力图上的一格颜色
